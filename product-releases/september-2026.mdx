## Why It Matters

These updates focus on two key pillars of annotation efficiency:

1. **Observability:** The analytics screen gives teams full visibility into annotation progress and usage metrics, enabling better project management.
2. **Data Freshness:** On-demand reindexing keeps search accurate and up-to-date without admin overhead or manual database operations.

Together, these enhancements help computer vision teams maintain accurate search results and monitor annotation workflows effectively.

## FAQs

**Q1. How do I trigger a project reindex?**
Use the new reindex button on the project UI to instantly refresh search results for that project.

**Q2. What metrics are available on the analytics screen?**
The analytics screen shows detailed annotation usage metrics including progress tracking, annotation counts, and project-level usage statistics.

**Q3. Is reindexing automatic or manual?**
Reindexing is now on-demand and manual — you trigger it via the UI button when you need search results refreshed.
