## November 2026

### Hosted Connector Launch

The Labellerr MCP server is now available as a managed, high-performance **Hosted Connector** with all **23 tools** fully supported and zero local installation required.

- **One URL for Claude**: Add `https://mcp.labellerr.com/mcp` as a custom connector across **Claude.ai**, **Claude Desktop**, and **Claude Code**.
- **Per-User OAuth Sign-in**: Users authenticate with their own Labellerr login in the browser and select their workspace. Tool calls execute under the signed-in user's individual roles and project permissions rather than a single static API key.
- **End-to-End Encryption & Security**: Stored sessions are encrypted; tokens given to Claude are stored only as one-way hashes. Removing the connector immediately revokes access.
- **Structured Claude Outputs**: Tools return concise, structured data models (IDs, names, status flags) and clear next steps, ensuring Claude never outputs API keys, secrets, or raw file contents into the chat.

### Improvements & Fixes

- **Pre-annotation flexibility**: `upload_preannotations` accepts COCO JSON either inline or via public URL (up to 25 MB) and returns a persistent `job_id` immediately upon submission. For larger datasets, `upload_preannotations_async` allows non-blocking asynchronous processing.
- **Data type resilience**: `project_list` and `search_projects` gracefully handle legacy projects without explicit data types without raising exceptions.
- **Cloud ingestion**: `dataset_create` supports folder-level scoping (`path`) within S3/GCS buckets and public Google Drive folder links.

## Earlier Releases

### Local MCP Server

The initial release of the Labellerr MCP Server operates locally over `stdio` using Python and Labellerr API credentials (`LABELLERR_API_KEY`, `LABELLERR_API_SECRET`, `LABELLERR_CLIENT_ID`).

- **23 Tools**: Full coverage across Project Management, Dataset Management, Annotation Operations, System Monitoring, and Querying.
- **Direct Local Uploads**: Includes `dataset_upload_files` and `dataset_upload_folder` for streaming local hard drive directories directly into Labellerr.
- **Full IDE Compatibility**: Supports Claude Desktop, Cursor, and Claude Code.
- See [Local MCP Server](/mcp/mcp-local-server) for full documentation and setup instructions.
