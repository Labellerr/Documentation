## Introduction

The **Labellerr MCP Server** lets AI assistants such as **Claude** work directly with your Labellerr workspace. Built on the [Model Context Protocol (MCP)](https://modelcontextprotocol.io), it turns plain-language requests into Labellerr actions: find datasets, import data from cloud storage or Google Drive, create label templates and projects, upload pre-annotations, track live progress, and export finished annotations.

```text Example Prompt
Create a project called "Shelf Audit" for product and price-tag boxes
on my "Store Images" dataset, then tell me when it is ready.
```

Labellerr offers the MCP server in two forms:

| Feature | Hosted connector (Recommended) | Local server |
| :--- | :--- | :--- |
| **How you add it** | Paste one URL into Claude | Install Python code and edit a config file |
| **How you sign in** | Your own Labellerr login, in the browser (OAuth) | API Key, API Secret, and Client ID in config file |
| **Permissions** | Your own Labellerr roles and project access | Whatever the API credentials allow |
| **Works with** | Claude.ai, Claude Desktop, Claude Code | Claude Desktop, Cursor, Claude Code |
| **Data sources** | Saved S3 and GCS connections, Google Drive links | S3 & GCS connections, plus local files and folders |
| **Long tasks** | Return a `job_id` you can track at any time | Run until finished inside the call |
| **Tools** | 23 tools | 23 tools |

## Connect the Hosted Connector

### Prerequisites

- A Labellerr account with access to at least one workspace.
- One of: **Claude.ai** (web), **Claude Desktop**, or **Claude Code**.
- Permission to add custom connectors in Claude (on Team and Enterprise plans, a workspace owner may need to allow custom connectors).

### Connector URL

```text Connector URL
https://mcp.labellerr.com/mcp
```

<Info>
  **Safe to Share**: The URL holds no secret or credentials. Every person signs in with their own Labellerr account, so it is completely safe to share this URL across your team.
</Info>

### Add the Connector

<Tabs>
  <Tab title="Claude.ai (Web)">
    <Steps>
      <Step title="Open Connectors">
        Navigate to **Settings** → **Connectors** in Claude.ai and select **Add custom connector**.
      </Step>
      <Step title="Add the URL">
        Name the connector `Labellerr` and paste `https://mcp.labellerr.com/mcp` as the URL. Click **Add**.
      </Step>
      <Step title="Sign in">
        Click **Connect**. Claude opens the Labellerr sign-in page in a new window. Sign in with your Labellerr account, choose your workspace on the consent page, and click **Allow**.
      </Step>
      <Step title="Enable in Chat">
        In a new chat, open the tools menu and ensure **Labellerr** is enabled.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Claude Desktop">
    <Steps>
      <Step title="Open Connectors">
        Open Claude Desktop, go to **Settings** → **Connectors**, and select **Add custom connector**.
      </Step>
      <Step title="Add the URL">
        Name the connector `Labellerr` and paste `https://mcp.labellerr.com/mcp` as the URL.
      </Step>
      <Step title="Sign in">
        Click **Connect**. In the browser window that opens, sign in with your Labellerr login, select your workspace, and click **Allow**.
      </Step>
    </Steps>

    <Note>
      Connectors added in Claude.ai also appear automatically in Claude Desktop when you are signed into the same Claude account.
    </Note>
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="Add the Connector CLI command">
        Run the following command in your terminal to register the connector for your user:
        ```bash
        claude mcp add --transport http --scope user labellerr https://mcp.labellerr.com/mcp
        ```
      </Step>
      <Step title="Authenticate">
        Start Claude Code, run `/mcp`, select `labellerr`, and choose **Authenticate**. Your browser will open the Labellerr sign-in page; sign in, choose your workspace, and click **Allow**.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Check the Connection

To verify that the connector is properly configured and active, ask Claude:

```text
Check my Labellerr connection.
```

Claude will call the `health` tool, returning:
- The server status and version
- Total tool count (**23 tools**)
- Your Labellerr `client_id`
- The user account you are authenticated as

## Sign-in and Permissions

### How Sign-in Works

The hosted connector uses standard **OAuth 2.0**. Claude never sees your password or login credentials:
1. You sign in on Labellerr's official login page.
2. You select your workspace on the consent screen.
3. Claude receives a scoped connector token valid exclusively with the Labellerr MCP server.

After signing in, every tool call runs with your own user identity. You see the exact same projects and datasets as in the Labellerr web app, and any permission restrictions that apply in the web app are enforced through Claude as well.

### What the Connector Stores

- **Encrypted authentication**: Your Labellerr sign-in session is stored encrypted, preventing you from having to sign in repeatedly.
- **One-way hashed tokens**: Tokens issued to Claude are stored only as secure one-way hashes.
- **Zero data retention**: The connector does not store your datasets, files, labels, or exports. All assets reside securely in Labellerr.
- **No secrets in responses**: Tool outputs never include API keys, passwords, or cloud credentials.

### Signing in Again

Your authentication token remains active for a standard session period. When it expires, Claude displays a **Connect** or **Authenticate** prompt for Labellerr. Simply authenticate again; any ongoing operations (imports, uploads, exports) continue running in Labellerr uninterrupted.

### Disconnecting

To revoke access, remove the Labellerr connector in Claude (**Settings** → **Connectors**, or `claude mcp remove labellerr` in Claude Code). Removing it immediately revokes the token and clears the stored session. Your active session in the Labellerr web app is not affected.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Claude doesn't show Labellerr tools" icon="eye-slash">
    - Verify that the connector is enabled for your current chat (check the tools menu in Claude.ai or Claude Desktop, or run `/mcp` in Claude Code).
    - If the connector prompts with **Connect** or **Authenticate**, sign in again.
    - Start a new chat session after adding the connector.
  </Accordion>

  <Accordion title="Sign-in is refused or fails" icon="triangle-exclamation">
    - Make sure you use the exact email and password associated with your Labellerr web app account.
    - On the consent screen, verify you select a workspace where you have active membership.
    - If you previously canceled the consent window, remove the connector in Claude and add it again.
  </Accordion>

  <Accordion title="Session expired or not signed in" icon="clock">
    - Your session token has expired. Click the connector prompt in Claude to authenticate again.
    - Long-running operations (imports, uploads, exports) are not lost when a session expires; they continue executing on Labellerr servers.
  </Accordion>

  <Accordion title="Server connectivity check" icon="heart-pulse">
    - Ask Claude: *"Check my Labellerr connection."*
    - The `health` tool will verify whether the server is reachable and identify the authenticated user.
    - If connectivity fails, contact [Labellerr Support](mailto:support@labellerr.com) with the error timestamp.
  </Accordion>
</AccordionGroup>
